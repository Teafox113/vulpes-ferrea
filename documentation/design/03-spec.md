# 03 造形規範

版本 0.3（r3，2026-11-13，對應字型 Version 0.300）。FOX 看過並同意方向後升 1.0。
本檔是唯一規範來源，對應的可執行版本是 `scripts/build_glyphs.py`（字形）與 `scripts/export_fonts.py`（字型檔）。
r2 的規範內容全部沿用，r3 只有增補，差異見 §0.1。

## 0.1 與 0.2 版的差異（r3）

| 項目 | 0.2（r2） | 0.3（r3） | 理由 |
| --- | --- | --- | --- |
| 字集 | ASCII 95 | **ASCII + 排版符號 + Windows-1252／Latin-1 全部**（224 碼位，另 48 個替換字） | 中文以外的日常輸入都不會缺字 |
| 零件 | 八種 | 新增**重音零件**（§4.1）、**楔形引號**（§4.2） | 歐文字母與彎引號 |
| 直引號 `' "` | 底端刃切 | **無切角直條** | 與彎引號的楔形區分 |
| `k` | 交叉臂 | **閉口小碗 + 斜腳**（織體式） | r2 的交點不乾淨 |
| `Q` | 斜畫穿過右下角 | **45° 尾巴從底橫穿出** | 與筆軸同向，不再是斜線例外 |
| `& @` | 試作 | 重畫：`&` 上迴圈加寬到 90；`@` 內 a 放大 | 小字級不糊 |
| 格點 | 15 | 縮放字（上標、分數、序數）用 **7.5**，登記豁免（§5.6） | 0.5 倍縮放的結果 |
| 字偶 | 單字對 | **字形分類（class）**，重音字自動跟隨基本字母（§7.3） | 字集變大後不能逐字列 |
| OpenType | 只有 kern | `kern pnum tnum zero case frac numr dnom`（§8） | |

## 0. 與 0.1 版的差異（r2）

| 項目 | 0.1（r1） | 0.2（r2） | 理由 |
| --- | --- | --- | --- |
| 小寫字腔 | 120 | **90** | 直畫：字腔：字間 = 90：90：90，黑白比 1:1，回到織體的柵欄密度 |
| 大寫字腔 | 180 | **150** | 跟著小寫收緊，大寫與小寫的灰度一致 |
| 小寫字身 | 300 | **270** | 90 + 90 + 90 |
| 大寫與數字字身 | 360 | **330** | 90 + 150 + 90 |
| 數字字寬 | 480 | **450** | 等寬 |
| 小寫直邊字腔 | 60 | **45** | 兩側相加 = 90 = 字腔 |
| 斜畫水平寬度 | 小寫 100／大寫 110 | **一律 90** | 落在格點上，斜畫看起來比直畫略輕，符合視覺補償 |
| 標點菱形半徑 | 48 | **60** | 小字級時句點不會消失 |
| 空格 | 240 | **210** | 字間變窄，空格跟著縮 |

STEM 90、BAR 60、切角尺寸、垂直度量都沒變。

## 1. 座標

- UPM 1000。y 向上，基線 y = 0。
- 字身從 x = 0 開始畫，最後整體右移左字腔。
- 輪廓方向：TrueType 外框順時針、內框逆時針；CFF（.otf）反過來，由產生器處理。

## 2. 模組

模組 **M = 30**。尺寸是 M 的倍數，節點落在半模組（15）上。

| 名稱 | 值 | 模組數 | 用途 |
| --- | --- | --- | --- |
| STEM | 90 | 3M | 直畫厚度 |
| BAR | 60 | 2M | 橫畫厚度 |
| HAIR | 30 | 1M | 缺口 |
| DW | 90 | 3M | 斜畫的水平寬度 |

## 3. 垂直度量

| 名稱 | y | 模組數 |
| --- | --- | --- |
| 升部 ASC | 780 | 26M |
| 大寫高 CAP | 720 | 24M |
| x 高 XH | 540 | 18M |
| 數學中線 | 285 | 符號 `+ = ~ < > -` 的中心 |
| 基線 | 0 | 0 |
| 降部 DESC | −210 | −7M |
| 行框（ascent／descent） | 900／−260 | |

- 數字與大寫同高。沒有曲線，不設溢出量。
- 例外：`$` 的上下短柱伸到 810／−90；`/ \ |` 與括號類跨過升部或降部，但不超出行框。

## 4. 零件

所有字形只能由這八種零件組成（0.2 新增「斜畫」與「回勾」為正式零件）。

| 零件 | 定義 |
| --- | --- |
| 直畫 | 寬 STEM 的矩形 |
| 橫畫 | 高 BAR 的矩形 |
| 斜畫 | 水平寬 DW 的平行四邊形，兩端水平切，兩端點都在格點上 |
| 主切角 | 45° 切角，小寫 3M（90），大寫與數字 4M（120） |
| 副切角 | 45° 切角，1M（30） |
| 刃切 | 45° 切角，2M（60），用在筆畫的自由端 |
| 狐耳 | 升部頂端的 V 形缺口，寬 = STEM，深 45 |
| 菱形 | 正方形轉 45°。句點類半徑 60、`i j` 的點 54、零的中心 60、`8` 的腰部缺口 30（用減的）、`%` 的點 75 |
| 回勾 | 降部直畫到 DESC 後，用橫畫往左回勾；外角主切角、內角補角，自由端刃切（`g j y`） |

### 4.1 重音零件（0.3 新增）

每個零件的左下角在 (0, 0)。小寫放在 y = 600（x 高 + 60），大寫放在 y = 765（大寫高 + 45），頂端不超過 900。

| 零件 | 小寫 | 大寫 | 造形 |
| --- | --- | --- | --- |
| acute／grave | 高 120 | 高 90 | 水平寬 90 的 45° 平行四邊形 |
| circumflex／caron | 高 105 | 同 | 兩條 45° 斜段，頂端留 60 的平頂 |
| dieresis | 高 90 | 同 | 兩個半徑 45 的菱形，間距 90 |
| ring | 180 × 180 | `Å` 專用：環與 A 頂橫熔接，頂端 870 | 主切角 60 的方環，字腔 60 |
| tilde | 高 120 | 高 105 | 橫畫 + 45° 斜段 + 橫畫 |
| macron | 高 60 | — | 兩端刃切的橫畫 |
| cedilla | 基線下 150 | 同 | 直畫 + 回勾 |

- 對齊：重音以基本字母的外框中心對齊，位移取 15 的倍數。
- 碰撞：重音超出字身時，字腔自動加寬，至少留 15（`ì í î ï` 因此比 `i` 寬）。
- `ì í î ï` 用無點 `ı`（dotlessi）當基本字母。

### 4.2 楔形引號（0.3 新增）

彎引號 `‘ ’ “ ” ‚ „` 用楔形：直畫（寬 90、高 210）底端切 90，尖端朝左下。`‘` 是 `’` 轉 180°。
不用逗號造形，因為 r2 的「菱形 + 斜尾」放到大寫高會被看成 `‹ ›`。

## 5. 規則

### 5.1 筆軸
- 字碗外框：左上與右下用主切角，右上與左下用副切角。
- 適用所有封閉或半封閉字碗：`o c e d b p q g O C D G Q U J 0 6 8 9 a B P R`。
- 例外（登記）：
  - 成對的括號 `( )` 上下兩角都用主切角（120），讓左右括號互為鏡像。
  - `B` 的上碗比下碗窄 30，主切角用小寫的 90，讓右腰露出缺口，與 `8` 區分。
  - `5` 的碗右上用主切角（不是副切角），配合直角的左上肩，與 `S` 區分。

### 5.2 切角配對
斜段厚度 = (STEM + BAR + 內切 − 外切) ÷ √2 ≈ 64。

| 外切 | 內切 |
| --- | --- |
| 2M（60） | 0（直角） |
| 3M（90） | 1M（30） |
| 4M（120） | 2M（60） |

副切角（1M）對應的內角一律直角。

### 5.3 端點
- 直畫的自由頂端：刃切在左上，尖在右上。
- 直畫的自由底端：刃切在右下，尖在左下。
- 橫畫的自由端：左端切左上，右端切右下。兩端都自由時就是平行四邊形。
- 升部頂端（`h d l b k`）：狐耳。
- 斜畫的自由端：水平切，不加刃切。
- 降部：直降的（`p q`）用刃切；回勾的（`g j y`）用回勾零件。
- 直畫接到橫畫或字碗的那一端不切。

### 5.4 對比
直畫 90，橫畫 60，斜段約 64，斜畫垂直厚度約 85（隨角度 81–87）。不得出現其他厚度。

### 5.5 角度
線段只能是 0°、45°、90°。例外是 §6 的斜線字。

### 5.6 格點
- 零件的原始節點（矩形角、切角點、斜畫端點、菱形頂點）必須落在 15 的格點上。
- **布林交點**（兩條斜畫交叉、斜畫穿過橫畫產生的點）可以不在格點上。自檢只對 §6 的字放行，並把每一個交點列在 `check.md`，人看得到。
- `i j` 的點用半徑 54，是唯一登記的非格點菱形。
- 標點沒有整字豁免：句號、逗號、冒號都已改成落格點的尺寸。
- **縮放字**（0.3）：上標 `¹ ² ³`、分子分母（`.numr .dnom`）、分數 `¼ ½ ¾`、序數 `ª º` 是原字形縮 0.5 倍，節點落在 7.5 的格點上，直畫 45、橫畫 30。這是唯一允許的縮放，自檢用 7.5 檢查。

## 6. 斜線字

允許 45° 以外斜線的字：

`k v w x z K M N R V W X Y Z 7 / \ % &`，以及 0.3 新增的 `® ™ ⁄ ‰ Ø ø ð ¥`、斜線零 `zero.slash`、所有以上述字母為基本字母的重音字（如 `Ñ Ý Ž`）。

- 斜畫水平寬度一律 90；分數線 `⁄` 例外為 60。
- `Q` 在 0.3 改用 45° 尾巴，不再是斜線例外。
- 逗號的尾巴改用 45°，不再是斜線例外。
- `< > ^` 用 45° 斜畫組成，不需要例外。

### 7.3 字偶（kern，0.3 改為分類）
寫在 `scripts/build_glyphs.py` 的 `KERN_LEFT`、`KERN_RIGHT`、`KERN_PAIRS`。

- 左類看字形的**右側**輪廓（例如 `L_T`：T 的右上懸空），右類看字形的**左側**輪廓（例如 `R_lr`：圓形小寫）。
- 重音字自動加入基本字母的分類（`Ý` 跟 `Y`、`é` 跟 `e`），不用另外列。
- 共 14 個左類、13 個右類、58 條規則，展開後約 1,300 對。
- 數值一律是 15 的倍數。主要值：`T` + 圓形小寫 −75、`L` + 引號 −90、句號逗號 + `T Y` −75、`V W` + 圓形小寫 −45。

## 8. OpenType 功能（0.3 新增）

| 功能 | 內容 |
| --- | --- |
| `kern` | §7.3 的分類字偶（預設開） |
| `tnum`／`pnum` | 預設等寬數字；`pnum` 換成 `.pnum` 比例數字，`tnum` 換回 |
| `zero` | `0` → `zero.slash`（斜線零） |
| `case` | 全大寫時：連字號、破折號、括號類、角引號、間隔號、項目符號上移到大寫中線；`¡ ¿` 移到基線上 |
| `frac` | `1/2` → 分子 + 分數線 + 分母（任意位數） |
| `numr`／`dnom` | 分子、分母數字 |

## 9. 檢查清單

提交任何字形前逐項確認：

- [ ] 只用了 §4 的零件
- [ ] 主切角在左上與右下，副切角在右上與左下（或已在 §5.1 登記例外）
- [ ] 內外切角符合 §5.2 的配對
- [ ] 自由端都依 §5.3 處理
- [ ] 原始節點在 15 的格點上；離格點的只有已登記的布林交點與縮放字（7.5）
- [ ] 重音字：重音沒有碰到鄰字，頂端不超過 900
- [ ] 高度對到 §3 的基準線
- [ ] 字寬與字腔符合 §7
- [ ] 放進 `minimum`、`Hamburgevons` 這類字串裡看過，黑白均勻
- [ ] 與易混字比對過：`O 0 o`、`S 5 s`、`I l 1 |`、`B 8`、`Z 2 z`、`G 6`、`g q 9`、`rn m`、`k K`、`ß B`、`’ ›`
