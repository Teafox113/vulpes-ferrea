## 3. 字形分組（r2 定案的骨架）

同一組共用骨架。

### 小寫

| 組 | 字 | 骨架 |
| --- | --- | --- |
| 直畫組 | `i l` | 單直畫；`l` 狐耳叉頂 |
| 拱組 | `n m h u r` | `n`；`u` 是 `n` 轉 180° |
| 碗組 | `o c e` | `o` |
| 碗加直畫 | `d b p q` | `o` + 直畫，依筆軸各自決定切角（不是單純鏡射） |
| 回勾降部 | `g j y` | 回勾零件；`g` = `q` 的碗 + 回勾，`y` = 開口的 `u` + 回勾 |
| 斜線組 | `v w x z k` | 斜畫（水平寬 90） |
| 獨立 | `a s t f` | |

### 大寫

| 組 | 字 | 骨架 |
| --- | --- | --- |
| 直橫組 | `H F E I L T` | `H`；`I` 上下有橫畫，與 `l 1` 區分 |
| 碗組 | `O C D G Q U J` | `O`；`G` = `C` 下半封口加內橫；`J` = `U` 左臂截短 |
| 半碗組 | `P R B` | `P`；`R` = `P` + 斜腳；`B` 上碗窄 30 |
| 斜線組 | `K M N V W X Y Z` | 斜畫；`M` 中央 V 停在 240 |
| 獨立 | `A S` | |

### 數字
`0–9` 等寬 450。`6 9` 互為旋轉，`0` 用中心菱形與 `O` 區分，`2` 用 45° 斜腰與 `Z` 區分，`5` 用直角肩與 `S` 區分，`8` 用腰部菱形缺口與 `B` 區分。

### 符號

| 組 | 字 | 骨架 |
| --- | --- | --- |
| 菱形組 | `. , : ; ! ?` | 菱形（半徑 60）+ 刃切直畫；逗號尾巴 45° |
| 引號組 | `' "` 與重音符 `` ` `` | r3：直引號是無切角直條；彎引號是楔形（§4.2）；重音符是 45° 斜畫 |
| 橫線組 | `- _ = + ~` | 橫畫；`~` 是橫畫 + 45° 斜段 |
| 角括組 | `< > ^` | 兩條 45° 斜畫；`^` 是 `<` 轉 90° |
| 斜線組 | `/ \ %` | 斜畫；`%` 的點用菱形 |
| 括號組 | `( ) [ ] { } |` | 直畫 + 橫畫；`(` 加主切角，`{` 加中央 45° 尖角 |
| 判斷型 | `@ & $ # *` | `@` 外框螺旋；`&` 上迴圈 + 下 C + 斜腳；`$` = `S` + 上下短柱；`#` 刃切直畫 + 刃切橫畫；`*` 直畫 + 兩條 45° 斜畫 |

### 歐文獨立字母（r3）

| 字 | 骨架 |
| --- | --- |
| `Æ Œ` | `A`／`O` 的左半 + `E` 的右半，共用中間直畫 |
| `æ œ` | `a`／`o` + `e`，重疊一個直畫 |
| `Ø ø` | `O`／`o` + 斜畫 |
| `Ð` | `D` + 穿過直畫的刃切橫畫 |
| `ð` | `o` 形字碗 + 向左上的斜畫 + 刃切橫畫 |
| `Þ þ` | 直畫 + 半碗（`þ` 的直畫上有狐耳、下到降部） |
| `ß` | 織體 ſʒ 寫法：長 s 直畫 + 45° 斜腰 + ʒ 形下碗 |

### OpenType 替換字（48）

`.numr` `.dnom` 各 10、`.pnum` 10、`zero.slash`、`.case` 17。

## 4. 繪製順序（實際）

r2 一次重畫：先套新度量重建 42 個控制字，再依骨架推導其餘 52 字，最後全字集過一輪易混字比對與字偶。

r3 再一次補齊第二、三期與 OpenType 功能，並重畫 `& @ Q k ß` 與引號。

下一步：
1. FOX 審 r3，並在 Windows 實際安裝測試。
2. 視需要：風格集 `ss01`（斷路）、`ss02`（哥德大寫）、第二字重。
3. 中文另案評估。

## 5. 命名與檔案

- 字形名用 Adobe Glyph List 慣例。
- 風格替換字加後綴：`a.ss01`、`zero.slash`。
- 版次用 `r1`、`r2` 遞增，每一版一個資料夾，舊版不覆蓋。
- `glyphs.json` 格式同 r1；r2 的 `meta` 另加 `space`、`kern`，`metrics` 另加 `diag_width`、`math_axis`、`width_lc`、`width_uc`、`figure_advance`、`sidebearing_uc`、`sidebearing_point`。
- r3 的 `glyphs.json`：每個字形另加 `unicodes`（清單，一字可多碼位；替換字為空清單）；`meta` 另加 `features`（完整 .fea 原文）、`base_of`（重音字的基本字母）、`grid_exempt`（縮放字）、`diag_glyphs`。
