# 02 設計主軸與邏輯

## 1. 一句話

**把哥德織體的骨架，用切角鋼板重新鍛一次。**

賽博龐克和金屬哥德表面上是兩種東西，但它們共用一件事：垂直、密集、銳利的節奏。這套字不拼貼兩種風格，只取它們重疊的地方。

## 2. 兩個來源各拿什麼

| | 取用 | 不取用 |
| --- | --- | --- |
| 哥德織體（Textura） | 垂直直畫的柵欄節奏、斷筆（曲線折成直線）、菱形端點、分叉的升部、窄長比例 | 筆寫的粗細漸變、繁複的大寫、髮絲細線、難認的古字形（長 s、古式 r 等） |
| 賽博龐克／機械字 | 只有直線與 45° 切角、模組格線、等寬數字、八角形字碗 | 發光、故障、掃描線等效果（那是排版時加的，不該畫進字形） |

結果要能這樣讀：遠看是一排鐵柵，近看每個端點都是刀口。

## 3. 四條設計邏輯

每個字形的決定都要能回推到這四條。推不回去的造形不留。

### 3.1 柵欄
小寫的直畫 90、字腔 120、字與字之間的白 120（左右字腔各 60）。字腔與字間等寬，一行字就是等距的直條。這是織體的核心，也是條碼和散熱鰭片的樣子。

### 3.2 斷筆
沒有曲線。所有轉彎都是 45° 切角。織體本來就把圓折成六角，這裡折得更徹底，折成不對稱的八角。

### 3.3 筆軸
切角不對稱：大切角只落在左上與右下，右上與左下只有小切角。這是把寬頭筆「固定筆角」的觀念抽象化，讓整套字有同一個方向的斜向張力，也讓字看起來像被同一把刀從同一個角度削過。

要說清楚的是：這是借用觀念，不是重現筆寫。真正的織體筆角造成的粗細分布和這裡不同。

### 3.4 鍛接
直畫厚 90、橫畫厚 60、斜段厚約 64。橫細直粗保留哥德的垂直重心；切角的內外尺寸成對固定，讓斜段厚度永遠接近橫畫。零件少、尺寸固定，像標準化的鋼材。

## 4. 專屬記號

這是 FOX 的字，要有別人的字沒有的東西。記號只有三個，不再加。

| 記號 | 位置 | 來歷 |
| --- | --- | --- |
| 狐耳 | 升部頂端的 V 形缺口（`h d l`，之後 `b k`） | 哥德字的分叉升部，剛好是一對耳朵 |
| 刃切 | 直畫的自由端：頂端尖在右上，底端尖在左下 | 織體的菱形腳，簡化成一刀 |
| 菱形 | 句點、冒號、`i` 的點、零的中心 | 織體的菱形端點，直接留用 |

## 5. 氣質與用途

- 氣質：冷、硬、精確、帶一點儀式感。
- 適合：標題、標誌、介面標題、遊戲與個人作品的識別。
- 不適合：長篇內文、小於 14px 的說明文字。窄而密的字不耐小字級，這是風格的代價，不打算解決。

## 6. 取捨紀錄

| 決定 | 選了 | 沒選 | 理由 |
| --- | --- | --- | --- |
| 曲線 | 完全不用 | 圓角或局部圓弧 | 一有曲線就變成一般的科技字，哥德的斷筆感會消失 |
| 小寫字形 | 現代字形 | 哥德古字形 | 專屬字型要能日常使用，看不懂就沒有用 |
| 大寫 | 與小寫同一套零件 | 裝飾性哥德大寫 | 先求系統一致。要不要加裝飾列為待決 |
| 數字 | 預設等寬 | 預設比例寬 | 介面、程式、數據場景多，等寬較實用 |
| 零 | 中心菱形 | 斜線零 | 斜線會和筆軸的斜切混在一起 |
| `a` | 雙層 | 單層 | 單層 `a` 會和 `o`、`d` 太像 |
| 對比 | 橫細直粗 | 等線 | 等線會失去哥德的垂直感 |
