# 05 出處與授權

## 1. 原創性聲明

本字型的所有輪廓都由 `docs/03-spec.md` 的規則經程式產生，沒有描摹、轉換或修改任何既有字型的輪廓。以下列的是觀念上的來源，不是素材來源。

## 2. 歷史來源

| 來源 | 取用的觀念 |
| --- | --- |
| 織體（Textura／Textualis），中世紀晚期北歐的書寫體，古騰堡聖經的活字即以此為本 | 垂直直畫的等距節奏、把圓折成直線的斷筆、菱形端點、窄長比例 |
| 哥德字體的分叉升部 | 狐耳缺口 |
| 寬頭筆的固定筆角（織體約 40–45°） | 筆軸：切角固定在同一條對角線上。只借觀念，沒有重現筆寫的粗細 |
| 二十世紀的直線幾何字與模組字（切角矩形、格線造字的傳統） | 只用直線與 45°、八角形字碗、模組格線 |
| 七段顯示器與機械標示字 | 等寬數字、數字的直角骨架 |

## 3. 當代參考

研究階段看過、用來確認方向可行的案例。沒有取用它們的造形。

- Gryffensee（Christian Thalmann）：以「哥德體中的幾何無襯線」為目標，用有限的直線段與圓弧、正交或 45° 切口造字。討論串裡有兩點直接影響本專案：45° 切口會讓直畫看起來變輕變短；傳統哥德大寫難認，需要易讀的替換形。https://typedrawers.com/discussion/comment/3533
- TypeMedia 2021，Sander Pedersen 的畢業作品：小寫是簡化到沒有曲線、沒有細線的哥德體，另有以格線模組構成的壓縮體。https://2021.typemedia.org/sander.html
- 織體書寫教學（筆角、斷筆、菱形襯腳、圓字群其實是六角形）：https://ypen-com.pages.dev/blackletter-calligraphy-guide

流程與工具的出處列在 `01-process.md` 文末。

## 4. 與既有字型的區別

幾何哥德體與切角科技字都已經有很多。本字型的區別在三點的組合：切角不對稱且固定軸向、狐耳、橫細直粗的固定配對。

### 4.1 名稱查核（2026-11-13，網路搜尋）

| 名稱 | 結果 |
| --- | --- |
| Vulpes Ferrea | 沒有同名字型 |
| 鐵狐體 | 沒有同名字型 |
| Vulpes（單字） | 已有 Marco Ballarè 2015 年的 grotesque 無襯線字型〈Vulpes〉；另有美國註冊商標 VULPES（Vulpes Corp.，化學與醫藥類）。因此本字型對外一律使用完整名稱，不簡稱 Vulpes |
| Vulpa | Dave Rowland Type 的襯線字型，已停售，名稱相近但不相同 |

這次是網路搜尋，不是正式商標檢索。若要註冊商標或商業販售，應另到智慧局與 USPTO 正式查核。

### 4.2 原創性查核（2026-11-13）

- 所有輪廓由 `scripts/build_glyphs.py` 依規範計算，倉庫內沒有任何外部字型檔或外部輪廓。
- 參考作品（本檔 §3）只取觀念，沒有取用造形。

## 5. 授權

- 字型以 **SIL Open Font License 1.1** 釋出（2026-11-13 FOX 決定），全文見根目錄 `OFL.txt`。可自由使用、內嵌、修改、再散布，包括商業用途；不能單獨販售字型檔；改版必須同樣用 OFL，且不得冒用原作者名義。未設定保留字型名稱（Reserved Font Name）。
- 著作權人列在 `AUTHORS.txt`（FOX）。輪廓產生器、規範與工程由 Claude Opus 5.5（Anthropic）在 FOX 指示下完成，列於 `CONTRIBUTORS.txt` 以示透明，不是著作權人。
- 設計文件與建置程式碼隨字型一併以 OFL 散布。
- 使用的工具（fontTools、shapely、ufoLib2、brotli、Pillow、opentype-sanitizer）都是寬鬆開源授權，不影響產出字型的權利。TTF 的 hinting 由 ttfautohint（FreeType License／GPLv2）自動產生；業界普遍視其輸出不受工具授權約束，但本專案未找到官方原文，若有疑慮可改用不含 hinting 的 OTF。

## 6. 協作者守則

- 不下載別人的字型來描、改、或抽取輪廓。
- 不把外部字型檔放進本倉庫。
- 參考別人的作品時，把連結與取用了什麼觀念補進本檔 §3。
