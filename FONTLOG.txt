FONTLOG for Vulpes Ferrea
=========================

This file provides detailed information on the Vulpes Ferrea font software.
This information should be distributed along with the Vulpes Ferrea fonts
and any derivative works.


Basic Font Information
----------------------

Vulpes Ferrea ("Iron Fox", 鐵狐體) rebuilds the skeleton of Textura blackletter
with chamfered cyberpunk geometry. There are no curves: every outline is made of
straight segments at 0, 45 and 90 degrees (plus a registered set of diagonal
letters), placed on a 30-unit module grid with nodes on a 15-unit half grid.

Design rules:
- Picket fence rhythm: in lowercase, stem, counter and the space between letters
  are all 90 units, the dense vertical texture of Textura.
- Broken strokes: every turn is a 45-degree chamfer.
- Pen axis: large chamfers only at top-left and bottom-right, small ones at
  top-right and bottom-left, as if every letter were cut by the same blade.
- Fixed contrast: stems 90, bars 60, diagonals about 64.
- Three signature marks: the "fox ear" notch on ascenders, the blade cut on free
  stroke ends, and the diamond (period, i-dot, the centre of zero).

Outlines are not drawn by hand. They are computed by scripts/build_glyphs.py
from the specification in documentation/design/03-spec.md. No outline was
traced, converted or copied from any existing font.

Intended use: display, titles, logos, interface headings and game UI at 20 px
and above. Not intended for long text.

Character set: Basic Latin, Latin-1 Supplement and the full Windows-1252 code
page (224 code points), plus 48 OpenType alternates.

OpenType features: kern (class based), pnum/tnum (tabular figures by default),
zero (slashed zero), case (case-sensitive punctuation), frac, numr, dnom.


ChangeLog
---------

20 November 2026 (FOX) Vulpes Ferrea Version 0.310
- Redesigned v, w, x and V, W, X with a broken-stroke skeleton (Codex
  proposal 004, option A), tying them to the n, u, m, H, N picket rhythm:
  - v / V: a stem reaches the baseline, a rising diagonal climbs to a short
    stem (Textura form). w / W repeat the move with three stems.
  - x / X: both strokes run stem, 45-degree diagonal, stem and cross in the
    middle, so every corner ends in a bladed stem foot.
- Kerning: V and W lose their diagonal left side; V/W + round lowercase
  reduced from -45 to -30.

13 November 2026 (FOX) Vulpes Ferrea Version 0.300 (design revision r3)
- Completed every character outside Chinese: typographic punctuation, currency,
  superiors and fractions, and all Windows-1252 / Latin-1 letters.
- Accented letters composed from base letters and a new set of accent parts.
- Redesigned k, Q, &, @, ß (Textura long-s + ezh form), and the quotes:
  straight quotes are plain bars, curly quotes are wedges.
- Class-based kerning; OpenType features pnum, tnum, zero, case, frac, numr, dnom.
- OTF, autohinted TTF, WOFF2 and UFO outputs; all pass OTS.
- Released under the SIL Open Font License 1.1.

12 November 2026 (FOX) Design revision r2
- Darker colour: lowercase counters 120 -> 90 (black-to-white ratio 1:1).
- All diagonals 90 units wide with endpoints on the grid.
- Completed the 95 printable ASCII characters.

12 November 2026 (FOX) Design revision r1
- Project start: concept, specification and 42 control glyphs.
